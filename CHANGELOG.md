# Changelog

All notable changes to the **NDC vs GDS Distribution Decision Assistant** are documented in this file.

> **Important Note on Version 1.0 vs. Version 2.0 Financial Results:**
> Scenario outputs generated by Version 2.0 will differ materially from Version 1.0—even for similar booking volumes and fees. Version 2.0 corrects several commercial simplifications from Version 1.0 (notably GDS surcharge accounting as airline revenue recovery vs. expense, contribution margin vs. gross revenue, blended partial migration, Look-to-Book shopping API costs, and upfront CAPEX/OPEX/transition expenses). Version 2.0 results are generally more conservative and commercially realistic than Version 1.0.

---

## [2.0.0] — 2026-11-28

### Financial Model Corrections (P0 & P1)
- **Corrected GDS Distribution Surcharge Accounting:** Replaced the v1.0 formula that always added GDS surcharges as a cost with an explicit three-way selector (*No surcharge*, *Airline revenue recovery* with retention %, or *Additional airline expense*), preventing double-counting and separating per-ticket charges via `ticketsPerBooking`.
- **Separated Gross Revenue from Contribution Margin:** Added independent `ancillaryContributionMarginPercent` and `pricingContributionMarginPercent` inputs plus signed revenue uplift support (allowing downside negative uplift modeling).
- **Introduced Blended Channel Economics (0%–100% Migration):** Replaced the v1.0 all-or-nothing 100% GDS vs. 100% NDC comparison with partial migration splitting eligible volume into migrated NDC bookings and remaining legacy GDS bookings.
- **Added Look-to-Book (L2B) Shopping API Economics:** Modeled incremental shopping API requests and marginal cost per request with an included-request allowance and an explicit toggle when shopping costs are bundled in the base NDC fee.
- **Added CAPEX, Fixed OPEX, Transition Costs & Cash-Flow Payback:** Added 36-month cumulative cash-flow timeline, Year 1 cash flow, exact transition-adjusted payback period (displaying *"Payback not achieved"* when unrecoverable), 3-year cash ROI on CAPEX, and a clearly separated optional CAPEX P&L allocation view.
- **Redesigned Break-Even Ancillary Uplift Logic:** Replaced simple break-even percentage with a four-state structured result (*No additional uplift required*, *Exact % uplift required*, *Not achievable*, *Insufficient data*) eliminating `NaN`, `Infinity`, and misleading `0%` edge cases.

### New Product & UX Capabilities
- **Basic & Advanced Parameter Modes:** Made all 29 commercial assumptions editable with inline units, bounds, help tooltips, and non-blocking commercial sanity warnings.
- **Executive Dashboard Redesign:** Upgraded to 9 reconciled KPI cards, signed Monthly Financial Contribution Bridge (no longer stacking expenses and revenue into one positive bar), Blended Distribution Cost breakdown, 36-Month Cumulative Cash Flow chart, and Per-Booking Unit Economics reconciliation table.
- **Multi-Scenario Comparison:** Added 3 default scenario templates (*Conservative*, *Balanced / Hybrid*, *Accelerated*) with create, duplicate, rename, independent editing, side-by-side comparison table/chart, delete, and reset.
- **Two-Way Sensitivity Analysis:** Added 4 interactive heatmaps (*NDC Cost vs. Ancillary Uplift*, *Migration % vs. NDC Cost*, *Surcharge Recovery % vs. NDC Cost*, *Look-to-Book vs. NDC Cost*) plus highest-influence assumption ranking—all computed via the central engine.
- **Explainable Recommendation Engine:** Upgraded to 4 states (*Favorable*, *Hybrid / Conditional*, *Unfavorable*, *Insufficient Information*) with configurable illustrative thresholds, automated downside sensitivity probe, drivers, risks, and validation checklist.
- **Persistence & Secure Export:** Added opt-in browser `localStorage` persistence, CSV export with formula-injection neutralization, validated JSON export/import, and print-friendly PDF styling.

### Engineering, Security, SEO & Deployment Readiness
- Replaced runtime Tailwind Play CDN and external Google Fonts CDN with locally compiled Tailwind CSS v4 (`@tailwindcss/vite`) and locally bundled `@fontsource` fonts (`Plus Jakarta Sans`, `JetBrains Mono`).
- Added comprehensive Vitest automated test suite (`tests/*.test.ts`) including independent verification of the Mandatory Reference Scenario.
- Added ESLint 9 flat config (`npm run lint`), GitHub Actions CI (`.github/workflows/ci.yml`), Vercel static deployment config with CSP and security headers (`vercel.json`), SEO/OpenGraph/Twitter/JSON-LD metadata, favicon, social preview SVG, `robots.txt`, and `sitemap.xml`.
- Added supporting documentation suite under `docs/` (`FINANCIAL_MODEL.md`, `ARCHITECTURE.md`, `PRODUCT_DECISIONS.md`, `INTERVIEW_GUIDE.md`, `DEPLOYMENT.md`).
